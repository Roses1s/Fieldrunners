# Field Defense

Браузерная tower-defense игра в жанре «защита базы» (дух классических мобильных TD).
Сделана как **оригинальный проект**: собственные карты, собственные названия и брендинг,
вся графика генерируется кодом, весь звук синтезируется Web Audio.

**Целевое устройство:** Samsung Galaxy A56 (6.7", 1080×2340, 120 Гц), ландшафт, управление пальцем.
**Зависимости:** ноль. Ни npm-пакетов, ни CDN, ни внешних файлов изображений/звука. Работает офлайн.

---

## Запуск

### Вариант 1 — дев-сервер (модульные исходники)

```bash
node tools/serve.mjs 8080      # слушает 0.0.0.0:8080
# открыть http://localhost:8080/
```

ES6-модули не загружаются по `file://`, поэтому для исходников нужен любой статический сервер.
Отладочный режим: `http://localhost:8080/?debug=1` — FPS-счётчик и метрики кадра;
клавиша **F** включает/выключает плашку, **G** в бою показывает сетку с flow-field.

### Вариант 2 — единый файл (офлайн, работает с `file://`)

```bash
node build.mjs                 # собирает dist/index.html
```

`dist/index.html` — один самодостаточный файл (~393 КБ, 54 модуля, без `import`/`export` внутри).
Его можно скинуть на телефон, открыть из файловой системы или разместить где угодно без сервера.
Service Worker (`sw.js`) регистрируется только по `http(s)` — с `file://` игра просто работает без кэша.

## Управление

| Жест | Действие |
|---|---|
| Тап по пустой клетке | Радиальное меню постройки вокруг клетки |
| Тап по иконке башни | Построить (серые иконки = не хватает денег) |
| Двойной тап по клетке | Быстрая постройка последней выбранной башни (минуя меню) |
| Тап по башне | Панель: улучшение / продажа / режим прицеливания |
| Тап мимо | Закрыть радиальное меню |
| Драг одним пальцем | Панорамирование карты |
| Щипок двумя пальцами | Зум 0.6×–2.6× |
| Двойной тап по врагу/башне | — (обработка мультитапов в `TouchInput`) |

Кнопки UI не меньше 44×44 px.

Клавиатура (для десктопа — на телефоне всё делается жестами):

| Клавиша | Действие | Где работает |
|---|---|---|
| `Space` | вызвать следующую волну досрочно | бой |
| `P` / `Esc` | пауза (в паузе — выйти из неё) | бой / пауза |
| `1` `2` `3` | скорость ×1 / ×2 / ×3 | бой |
| `U` | улучшить выбранную башню | бой |
| `S` | продать выбранную башню | бой |
| `T` | следующий режим прицеливания | бой |
| `G` | показать/скрыть сетку клеток | бой |
| `F` | отладочная плашка (FPS, пути, зоны) | везде |
| `Enter` | «Играть» / «Повторить» | меню, выбор карты, экран итогов |
| `←` `→` | переключить карточку карты | выбор карты |
| `Esc` | назад | меню, выбор карты |

Режимы прицеливания башни: **ближайший к выходу → самый сильный → самый быстрый → первый в радиусе**.

## Содержание прототипа

- **4 карты.** `grasslands` (20×12, фиксированный путь), `desert` (24×14, открытый maze),
  `magma` (22×13, лава и два входа) и `city` (26×15, финальный городской maze с двумя входами).
- **8 башен × 3 уровня.** Gatling (дешёвый поток), Glue (замедление), Missile (хоуминг + сплэш),
  Tesla (цепная молния), Пиро (конус огня + поджог), Лазер (прошивающий луч с нарастанием урона),
  Улей (рой самонаводящихся пчёл) и Ядерная мортира (огромный сплэш с ослабленным эпицентром).
  Новые башни открываются за суммарные звёзды: Пиро — 3★, Лазер — 5★, Улей — 8★, Ядерная — 11★.
- **7 типов врагов.** Солдат, бегун, мотоциклист, вертолёт (летит по прямой, игнорирует лабиринт),
  тяжёлая броня (броня + иммунитет к замедлению), транспорт (при смерти высаживает десант),
  босс (волны 10 и 20, на 20-й — два; регенерация, стоит 5 жизней).
- **20 волн + бесконечный режим.** HP врагов растут ×1.15 за волну (солдат: 20 → 70 к волне 10, ×14.2 к волне 20).
- **Экономика.** Старт: 100 монет, 20 жизней. Награда за убийство + бонус за волну (8 + 3·n)
  + бонус за досрочный вызов (остаток времени × 0.5). Продажа: `floor(вложено × 0.75)`.
- **Звёзды.** 3 ★ — ноль протечек, 2 ★ — меньше 5, 1 ★ — за прохождение. Прогресс в LocalStorage
  (открытые карты, звёзды, рекорды, всего монет, настройки звука и скорости).

## Архитектура

```
js/
├── game.js            ядро: стек сцен, фикс. шаг 1/60, FPS, safe-area, orientation, visibility
├── main.js            boot: canvas + DPR, TouchInput, ?debug, регистрация sw.js
├── scenes/            Scene (базовый), Menu, MapSelect, Game, Pause, GameOver, GameHud
├── entities/          Tower, Enemy, Projectile (пул), Effect (пул)
│   ├── towers/        Gatling, Glue, Missile, Tesla, Flame, Laser, Hive, Nuke + реестр
│   └── enemies/       Soldier, FastRunner, Motorcycle, Helicopter, HeavyArmor, Transport, Boss
├── systems/           Grid, Pathfinding, Wave, Economy, Upgrade, Collision,
│                      Particle, Audio, Save, Render
├── maps/              map_grasslands, map_desert, map_magma, map_city, MapData
├── data/              TowerData, EnemyData — все балансные числа в одном месте
└── utils/             Constants, MathUtil, Vector2, SpriteSheet, Camera, TouchInput, Draw
```

Ключевые решения:

- **Логика отделена от рендера.** Симуляция идёт фиксированными шагами `1/60` с аккумулятором
  (не больше 5 шагов за кадр — защита от «спирали смерти»), рендер — один раз за кадр.
  На 120 Гц это значит 2 кадра отрисовки на один шаг логики.
- **Пауза при `visibilitychange`** — ушёл в фон, игра остановилась, звук выключен.
- **A\* с манхэттенской эвристикой** + волновой flow-field до выходов. При постройке/продаже
  пересчитываются маршруты всех врагов (кэш путей по `version`). Полная блокировка пути запрещена.
- **Проверка «не замуровать врага»** — один BFS по временному полю с учётом виртуально занятой клетки
  (O(клеток) вместо A* на каждый источник). На maze-карте это дало ~5.6× ускорение валидации стройки.
- **Воздух летит по прямой** от входа к выходу, игнорируя лабиринт и наземные башни; по воздуху работают Missile, Tesla, Laser, Hive и Nuke.
- **Вся графика — процедурные спрайты** (`SpriteSheet.js`): ленивая генерация при первом обращении,
  упаковка в атлас, силуэты для «недоступных» башен, кадры анимации ходьбы. 96 спрайтов, атлас ~264K px.
- **Статика запекается в offscreen canvas** с `BG_SCALE=2` и dirty-флагом: тайлы, декор, разметка путей
  рисуются один раз, дальше — один `drawImage`.
- **Весь звук синтезируется** (`AudioSystem.js`): осцилляторы + шумовой буфер, лимит голосов,
  приоритеты (босс/взрывы перебивают очередь), музыка — процедурный луп.
- **Object pooling:** частицы 900, снаряды 400, эффекты 220, всплывающий текст урона 140.
  **Spatial hashing** (`CollisionSystem`, ячейка 64 px) для поиска целей и сплэша.
  **Culling** по `viewRect` камеры, батчинг через атлас.
- **Адаптив:** canvas под `devicePixelRatio` (кап 2× — на 120 Гц экономит заполнение),
  `viewport` с `user-scalable=no`, `env(safe-area-inset-*)` для выреза, подсказка «поверните телефон»
  в портрете, `screen.orientation.lock('landscape')` в try/catch (работает только в fullscreen).

## Тесты

> Пошаговая инструкция «как запустить и всё проверить» — в **[TESTING.md](TESTING.md)**:
> три способа запуска, проверка на реальном телефоне, отладочные инструменты
> (плашка `?debug=1`, сетка с flow-field по клавише `G`, доступ из консоли) и таблица
> «если что-то не так».

Все тесты — обычный Node без единой зависимости: собственный DOM/Canvas-моки
(`tests/dom-mock.mjs`), реальный код игры, никакой сети.

```bash
npm test                 # build + sim + render + boot + bundle (212 проверок)
node tests/sim.mjs       # 99 проверок логики: сетка, A*, волны, экономика, урон, новые башни, разблокировки
node tests/render.mjs    # 61 проверка отрисовки: все 109 спрайтов, запекание фона, боевой кадр,
                         # HUD на 5 размерах экрана (включая 780×360 — A56), перекрытия UI
node tests/boot.mjs      # 35 интеграционных: реальный Game + TouchInput, меню → карты → бой,
                         # тапы/драги/щипки/колесо, пауза, visibility, resize, 60 с боя на x3
node tests/bundle.mjs    # 17 проверок: dist/index.html запускается в headless-окружении
node tests/balance.mjs   # бот-автоигрок: полный прогон 20 волн на всех 4 картах
```

Текущий результат: **212/212 проверок зелёные**. Замер производительности симуляции:
**~0.15 мс на кадр** при 60 башнях и 180 врагах (бюджет кадра 16.6 мс).
В render- и bundle-тестах — ноль незнакомых методов Canvas2D и ноль исключений.

Бот из `tests/balance.mjs` (ставит башни у пути, улучшает до 3 уровня, вызывает волну досрочно):

| Карта | Итог | Жизни | Протечек | Звёзды |
|---|---|---|---|---|
| grasslands | победа 20/20 волн | 20/20 | 0 | 3 ★ |
| desert (maze) | победа 20/20 волн | 20/20 | 0 | 3 ★ |
| magma (два входа) | победа 20/20 волн | 20/20 | 0 | 3 ★ |
| city (финальный maze) | победа 20/20 волн | 15/20 | 1 | 2 ★ |

Бот выбирает часть башен случайно, поэтому протечки и звёзды гуляют от прогона к прогону;
устойчивый ориентир — все четыре карты доводятся до победы, а финальная остаётся самой нервной.

## Баланс: где крутить

Все числа лежат в `js/data/TowerData.js`, `js/data/EnemyData.js`, `js/utils/Constants.js`
и `js/maps/*.js` — ничего не зашито в логику.

| Что | Где | Текущее значение |
|---|---|---|
| Цены/урон/радиус башен | `data/TowerData.js` | Gatling $5, Glue $10, Missile $20, Tesla $70, Laser $40, Hive $30, Пиро $90, Nuke $120; разблокировки за 3/5/8/11 суммарных звёзд |
| HP/броня/скорость/награда врагов | `data/EnemyData.js` | солдат 20 HP, $2; танк броня 6; босс ×8 HP, 5 жизней |
| Рост сложности | `Constants.js` | `HP_SCALE_PER_WAVE = 1.15`, `TOTAL_WAVES = 20` |
| Формула урона | `entities/Enemy.js` | `max(1, damage − armor × (1 − pierceArmor))` |
| Состав волны | `systems/WaveSystem.js` | бюджет `(5 + n·1.95)·сложность`, групп `1 + floor(n/4)`, босс на 10 и 20 |
| Экономика | `Constants.js`, `systems/EconomySystem.js` | старт 100 монет / 20 жизней, бонус волны `8 + 3n`, продажа 0.75 |
| Пауза между волнами | `maps/*.js` | первая: grasslands 25 с, desert 35 с, magma 28 с, city 40 с; далее 15 с |
| Пулы и лимиты | `Constants.js` | PARTICLE 900, PROJECTILE 400, EFFECT 220, TEXT 140, MAX_DPR 2 |

Чтобы изменить сложность, достаточно править `data/` и прогонять `node tests/balance.mjs` —
он за секунды проигрывает все карты целиком и печатает итог.

## Известные ограничения прототипа

- Баланс проверен ботом, а не живым игроком; кривая сложности может потребовать ручной доводки.
- Рендер проверен на мок-контексте Canvas2D (все вызовы валидны), но финальную картинку
  стоит посмотреть глазами в браузере.
- Нет музыки «под ситуацию» (один процедурный луп), нет локализации кроме русского,
  нет ачивок, предметов/бустеров, Link/Power-башен и мета-валюты из более полных версий жанра.
- `assets/*` каталоги намеренно пустые: игра не использует внешние файлы.
